# Policies
 Policy Library

A collection of information security and governance policy templates, 
developed to reflect industry frameworks (ISO 27001, SOC 2) and 
practical GRC implementation experience.

## Contents
- Information Security Policy
- Acceptable Use Policy
- Vendor/Third-Party Risk Management Policy
- Access Control Policy

## Approach
Each policy is written to be framework-aligned but adaptable — 
structured with purpose, scope, roles & responsibilities, and 
review cadence sections.
